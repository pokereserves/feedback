# Poké Reserves feedback

Bug reports, data corrections and feature requests for [pokereserves.com](https://pokereserves.com).

This repository holds only the public issue tracker, so anyone can see what has been reported and what is planned.

## Before you open an issue

Everything posted here is public. **Do not post:**

- **Anything about where a card is kept** beyond what the owner has already made public, or anyone's address, contact details or real name
- **A request to remove a record about you:** use the [takedown page](https://pokereserves.com/takedown) or email [takedown@pokereserves.com](mailto:takedown@pokereserves.com) instead, so it stays private
- **A security problem:** report it privately through this repository's **Security** tab ("Report a vulnerability"), not as an issue

Search the [open issues](../../issues) first. If yours is already there, add a thumbs up rather than a new issue. That is how we see what matters most.

## What to report

### Something is wrong on the site

A page that errors, looks broken, or behaves oddly. Include:

- The page link
- What you expected and what happened instead
- Your device and browser, and a screenshot if it helps

### The data is wrong

A wrong card, cert, grade or sale, a duplicate copy, or a card that is missing. Include:

- The page link (card, copy or sale)
- What is wrong, and what it should be
- A public source that shows the right answer: the grader's cert page, an auction house's result page, or similar

Corrections without a source may take longer, because every change is checked against one.

### A feature idea

Something the site should do. Describe the problem you want solved, not just the feature: "I want to see every PSA 10 Charizard sold this year" is more useful than "add a filter". Requests are planned in the open, but there is no promise any will be built.

## What happens next

Issues are read and labelled, usually within a few days:

| Label | Meaning |
| --- | --- |
| `bug` | Something on the site is broken |
| `data` | A record needs correcting |
| `feature` | A new idea |
| `planned` | Accepted and on the list |
| `needs-source` | Waiting for a public source |
| `wontfix` | Not going ahead, with the reason in the issue |

Issues are closed when the fix is live on the site.
